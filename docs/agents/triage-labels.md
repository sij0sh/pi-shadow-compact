# Triage labels

Map canonical triage roles to these GitHub label strings.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be implemented. |

When a skill mentions a role, use its mapped GitHub label.
Edit the GitHub label column if the repository's vocabulary changes.
